Database Connection Error

PostgreSQL server is not running or unreachable

⚠️ What Happened? The application tried to connect to the PostgreSQL database but failed. This could mean:
  • PostgreSQL service is not running
  • Database credentials are incorrect
  • Database server is not accessible
How to Fix
  1. Start PostgreSQL Service
    Start-Service postgresql-x64-15
    Or use Windows Services (services.msc)
  2. Create Database
    psql -U postgres -c "CREATE DATABASE skillswap_db;"
  3. Update .env File
    Check your .env file with correct credentials:
    DB_HOST=localhost DB_PORT=5432 DB_NAME=skillswap_db DB_USER=postgres DB_PASSWORD=your_password
  4. Restart Application
    Refresh this page or restart the Flask app
Go Home

Keep the Flask app running. Once PostgreSQL starts, refresh this page.
